# Python reproduction of *Extensional rheometry of model liquids*

This repository reconstructs the simulations in:

> O. Hassager, Y. Wang, and Q. Huang, “Extensional rheometry of model liquids: Simulations of filament stretching,” *Physics of Fluids* **33**, 123108 (2021), DOI: 10.1063/5.0076347.

It contains:

- analytical steady and startup calculations for the scalar Rolie–Poly toy and DE-toy models;
- an Eulerian slender-filament solver for the differential models in Appendix A;
- a sparse Lagrangian history-integral solver, a Python translation of the authors' original MATLAB program;
- single-mode Maxwell and continuous BSW memory functions;
- scripts that generate every computational panel corresponding to Figures 2–10, a contact sheet, and a time-step convergence study;
- a new schematic corresponding to Figure 1 (the copyrighted experimental photograph is not copied);
- compressed NumPy data for every simulation;
- tests and a runnable Jupyter notebook.

## Run all figures

From this directory:

```bash
python -m pip install -r requirements.txt
python reproduce_all.py --output outputs --quality standard
```

For a quicker smoke test (coarser grids; the late-stage neck geometry in Figures 5, 7 and 8 is not converged at this resolution — see `ANALYSIS.md` §9.5 and §10.1):

```bash
python reproduce_all.py --output outputs_fast --quality fast
```

The script writes PNG panels to `outputs/figures`, numerical arrays to `outputs/data`, and a concise numerical audit to `outputs/reproduction_metrics.json`. The standard preset runs in about 15 s on a laptop. Two optional follow-ups:

```bash
python make_contact_sheet.py --output outputs      # one-page overview of all panels
python convergence_study.py --output outputs/convergence   # dt-convergence, both time schemes
```

## Repository layout

- `hassager2021/` — the package
  - `analytical.py` — homogeneous and steady formulas.
  - `eulerian.py` — Appendix-A differential-model solver (two area schemes, see the changelog).
  - `lagrangian.py` — sparse Lagrangian history-integral solver, with a selectable time discretization (see the changelog).
  - `spectra.py` — Maxwell and BSW memory functions.
  - `figures.py` — paper-figure presets, plotting and the metrics file.
- `reproduce_all.py` — command-line entry point (Figures 1–10).
- `convergence_study.py` — dt/grid convergence of both solvers and both discretizations.
- `make_contact_sheet.py` — one-page overview of all generated panels.
- `reproduce_hassager2021.ipynb` / `.html` — guided, executed notebook and its static export.
- `tests/` — pytest suite (14 tests, ~3 s).
- `ANALYSIS.md` — detailed scientific and numerical analysis, including source gaps, reconstruction choices, and the two discretization audits (§9–10).
- `outputs/` — committed results of the standard preset: `figures/*.png`, `data/*.npz` (≈6.5 MB of NumPy arrays for every simulation), `reproduction_metrics.json`, `contact_sheet.png`, `convergence/`. Everything in it is regenerated by the three commands above; delete it from the repository if you prefer to keep only source.

Requires Python ≥ 3.10; NumPy 1.26+ and 2.x are both supported.

## Reproduction status

The paper equations, the single-mode and BSW memory functions, the Lagrangian residual/Jacobian, the Wagner stretch law, and the reported model parameters are implemented directly. The Lagrangian solver is a translation of the authors' original MATLAB program; that program is not part of this repository, and the Eulerian driver, the BSW crossover time `tau_c`, and the production controller settings were not available to the reconstruction. Those gaps are never hidden:

- the Eulerian controller is reconstructed as an ideal midplane-rate constraint;
- the Lagrangian solver offers both the original MATLAB feedback law and an exact midplane-strain constraint;
- `tau_c/tau_m` is an exposed BSW parameter, with a Figure-8-calibrated default of `1e-3`;
- the code documents and handles the factor-of-three inconsistency in the Eulerian solvent term.

The standard preset reproduces the paper’s qualitative transitions and principal quantitative levels, but exact pixel-by-pixel identity cannot be claimed where the original inputs are missing.

## Changelog

### v1.1 — time-discretization audit of the Lagrangian solver

Checking the v1.0 output against the paper showed that the literal translation of the original MATLAB driver overshoots the analytical steady stress by about 4% at `dt=0.05` (2.82 vs 2.709 G0 in the Figure 6(b) preset), whereas the paper's Figures 6(b) and 8(a) show the simulated stress landing on the analytical line. The overshoot is a first-order time-discretization error (it halves when `dt` is halved) with three sources in the original scheme: the memory function is sampled half a step later than the deformation it multiplies (an "extra 0.5·dt" experiment in the original driver), the solvent force uses the old segment length, and the stretch equation is backward Euler with an explicit Wagner function.

`LagrangianConfig.time_discretization` now selects between:

- `"matlab_first_order"` — the original program's scheme, kept for comparison;
- `"second_order"` (default) — trapezoidal history quadrature consistent with the pre-history survival term, BDF2 Hencky rate in the solvent term, a θ-method (Crank–Nicolson when `dt <= tau_s`) for molecular stretch, the Stokes end correction evaluated at extrapolated positions, and relaxation modes with `tau_k < dt` lumped into the solvent viscosity (exact as `tau_k -> 0`; this matters for the broad BSW spectrum). A geometric Newton predictor keeps the iteration in its quadratic regime.

`convergence_study.py` shows the stress error falling as `dt^2` and both schemes converging to the same neck geometry. With the default scheme the simulated stresses for Figures 4(b), 6(b) and 8(a) now sit on the analytical curves, as in the paper, and those panels are drawn from the filament simulations (as in the paper) with the homogeneous analytical transient overlaid as an independent check. The notebook, tests and metrics were updated accordingly.

### v1.2 — Eulerian solver audit

`EulerianConfig.area_scheme` selects `"pointwise"` (default; the Hoyle–Fielding non-conservative upwind form with the rate constraint `v_u(1/2)=ε̇`, used for the paper's figures) or `"conservative"` (finite-volume flux form, volume conserved to round-off, controller closed on the discrete mid-cell true strain so tracking is exact to round-off). The two agree to <0.2% while the neck is resolved; `EulerianSnapshot.neck_cells` reports the resolution. Grid/CFL convergence and the sensitivity to the Stokes coefficient `c_s` (the one Eulerian parameter not fixed by the paper; `c_s=0.30` fits Figures 3 and 5 to 0.01 and Figure 2 to 0.02) are tabulated in `ANALYSIS.md` §10, and `convergence_study.py` now covers both solvers.

## Tests

```bash
python -m pytest -q
```

The tests check analytical limits, steady stress levels, BSW scaling, positive filament geometry, exact midplane tracking in the Lagrangian solver, reverse plate motion during relaxation, second-order convergence of the default time scheme, the documented first-order bias of the original scheme, agreement of the Lagrangian Oldroyd-B stress with the homogeneous solution, and the lumping of sub-step BSW modes.
